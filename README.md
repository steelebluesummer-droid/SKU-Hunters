# SKU-Hunters · AI 新品企划工作室

> **不是让 AI"帮写企划案"，而是让 AI 先做"商品机会决策"——**
> **把新品方向从"企划师的直觉"变成"证据可追溯、评分可排序的确定选择"。**

名创优品 × AI 先锋未来人才大赛参赛方案：一套**证据驱动的 AI 商品决策引擎**，重构商品中心「计划→研发」链路，实现从趋势洞察到企划案输出的智能化决策。

---

## 为什么是这个项目

名创优品的核心竞争力来自持续打造爆品，但高频上新的背后，是商品企划团队需要在有限时间内完成"发现机会—判断需求—定义商品—制定方案"的复杂决策。我们调研后发现四个痛点：

1. **信息分散**：社媒热点、用户原声、竞品动向、IP/设计趋势散落各处，靠手工刷帖汇总；
2. **机会判断靠经验**："做什么方向"没有结构化评分排序，判断质量随人员波动；
3. **创意到方案转换成本高**：一份完整企划案需跨职能多轮沟通，单案周期以周计；
4. **洞察无法沉淀**：每次开发的洞察与失败经验不结构化留存，不同品类团队重复探索。

**核心洞察**：这是一条典型的非结构化信息密集型决策流程——传统工具只能管"流程流转"，无法完成"信息→判断→方案"的转化，而这正是 AI 的能力所在。

## 与"直接让 AI 生成创意"的本质区别

大多数 AI 选品方案的路径是"输入品类 → AI 吐创意 → 人工挑"，本质是抽奖。SKU-Hunters 反过来：**先建证据，再生机会**。

```
传统生成式路径：  品类 → AI 生成创意 → 人工挑（创意无证据支撑）
SKU-Hunters：    五看证据 → 机会池评分排序 → 机会卡 → 企划案（每步可回溯到证据）
```

机会池中的每个方向都携带完整证据链：来自哪个趋势信号、哪些用户原声、对应哪些竞品空位。同时，名创的生意规则（价格带、成本上限、毛利率红线、IP 策略）前置为决策边界——AI 生成的任何方案必须通过毛利率硬校验，不达标自动回环重拟。**AI 输出的不是"一篇文案"，而是"一份天然符合生意规则的商业方案"。**

## 六步决策链路

```
① 企划约束输入 —— 品类/市场/价格带/成本上限/IP 策略/上新窗口
        ↓
② 五看并行洞察 —— 趋势 / 用户原声 / 竞品空位 × 名创内部数据 × 流行元素板
        ↓
③ 机会池构建 —— 多维洞察融合，评分排序，产出三张可验证的机会方向卡
        ↓
④ 机会方向创意化 —— 选定最优方向，生成商品概念
        ↓
⑤ 商品可行性验证 —— 定价/成本/毛利率红线校验，不达标自动回环重拟
        ↓
⑥ 新品企划决策输出 —— 定位/设计/规格/定价/IP 匹配/上市计划，支持对话式改稿
        ↓
飞书闭环：归档自动沉淀多维表格 + 团队群通知 → 证据回流，持续进化
```

## 技术栈

**FastAPI** · **Pydantic**（输入输出契约强制）· **React + Ant Design + ECharts**（企划工作室前端）· **飞书**（多维表格台账 / 群机器人通知 / Aily 发起入口）

数据策略：**三态模式**——fixture（冻结演示）/ crawled（本地采集 JSON + LLM 二次分析，默认）/ live（飞书实时）；真实采集证据优先、LLM 生成兜底，不造假数据回退。

## 快速开始

```bash
git clone https://github.com/steelebluesummer-droid/SKU-Hunters.git
cd SKU-Hunters

# 后端
cd backend
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env   # 填入 LLM Key 与飞书凭证（可选）
./venv/Scripts/python -m uvicorn app.main:app --port 8000

# 前端
cd ../frontend
npm install && npm run dev   # → http://localhost:5173
```

完整演示走查见 [演示手册](docs/guides/demo-walkthrough.md)；飞书归档同步端到端验证：`python scripts/e2e_bitable_archive.py`。

## 项目结构

```
backend/
  app/planning/     六步企划管线（洞察解析 / 机会引擎 / 企划卡组装 / 成本校验 / 编排）
  app/insights/     社媒证据加载（真实采集数据 → 五看洞察契约）

  app/services/     即梦图片生成等外部服务
  feishu/           飞书对接（认证 / 企划通知 / 表格同步）
  data/evidence/    真实采集的社媒证据（按品类落盘）
frontend/
  src/features/     任务中心 / 洞察 / 机会 / 企划卡 / 数据看板 / 流行元素板
docs/               设计文档、指南与 API 契约
```
