## 项目定位

构建一套面向名创优品全球商品开发全流程的 **AI Product Committee（AI 商品开发智能决策引擎）**，以多 Agent 协同决策替代传统依赖人工经验的商品开发模式，实现从趋势洞察、产品立项、上市验证到反馈学习的智能闭环。

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/your-org/SKU-Hunters.git
cd SKU-Hunters

# 后端环境
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 运行测试
cd backend
pytest tests/
```
